## 1. 项目概述

### 1.1 项目简介

本项目是SRM（Supplier Relationship Management，供应商关系管理）系统的前端应用，采用微前端架构，基于Choerodon UI组件库和HZero框架构建。项目主要服务于企业级供应商管理业务，涵盖风险监控、供应商黑名单管理、企业尽职调查、事件更新汇总等多个业务模块。

### 1.2 项目名称与版本

- **项目名称**: srm-front-sdat
- **当前版本**: 1.67.0
- **发布地址**: https://nexus.going-link.com/repository/zhenyun-npm-source/

### 1.3 核心业务模块

根据代码分析，项目包含以下核心业务模块：

- **风险监控业务**（RiskControlMonitorBusiness）：企业风险监控核心页面，支持风险扫描和企业管理
- **风险控制工作台**（RiskControlWorkbench/RiskControlWorkbenchNew）：综合风险控制工作台，包含事件监控、风险凭证管理
- **供应商黑名单管理**（SupplierBlacklistManage）：供应商黑名单的增删改查和详情查看
- **企业尽职调查**（CorpDueDiligence）：企业关系和投资关系的动态卡片展示
- **事件更新汇总**（EventUpdateSummary）：风险事件的定义、详情和操作记录
- **关系挖掘**（RelationStaticMining/RelationStaticMiningQxb）：企业关系图谱和挖掘历史
- **AI智能体管理**（AIAgentMgt）：AI应用和服务配置管理
- **银行直接链接**（BankEnterDirectLink）：银行对账单查询和客户账户管理
- **卡片分发管理**（CardsDistribution）：数据表和订阅管理

## 4. 代码规范

### 4.1 代码风格标准

本项目采用以下代码风格标准：

**ESLint配置继承**：
- 基础配置：airbnb
- 代码格式化：prettier

**核心规则**：
- 使用babel-eslint解析器
- 支持ES2020语法特性
- 支持Legacy Decorators（装饰器语法）
- JSX文件扩展名：`.js`, `.jsx`, `.tsx`

### 4.2 命名规范

**文件和目录命名**：
- 组件文件：PascalCase（首字母大写），如 `RiskScanModal.js`
- 工具文件：camelCase（驼峰命名），如 `formatDate.js`
- 样式文件：与组件文件同名，如 `index.less`
- 目录名称：camelCase或kebab-case

**变量和函数命名**：
- 变量：camelCase，语义化命名
- 常量：UPPER_SNAKE_CASE
- 函数：以动词开头，如 `handleSave`, `fetchData`
- React组件：PascalCase

### 4.3 代码注释规范

**文件头注释**（必须包含）：
```javascript
/**
 * 创建时间: YYYY-MM-DD HH:mm:ss
 * 文件名: xxx.js
 * 文件描述: 功能描述
 * 作者: Felix(LQX5731@163.com)
 * 版本号: X.X.X
 * 最后更新时间: YYYY-MM-DD HH:mm:ss
 */
```

**函数级注释**：
```javascript
/**
 * 函数功能描述
 * @param {参数类型} 参数名 - 参数描述
 * @returns {返回类型} 返回描述
 */
function functionName(param) {
  // 实现代码
}
```

### 4.4 CSS/LESS规范

**样式命名**：
- 使用BEM命名规范：`block__element--modifier`
- 示例：`.header__logo--active`

**LESS编写规范**：
- 避免深度选择器嵌套（最多3层）
- 使用变量管理颜色和尺寸
- 提取公共样式到mixins
- 组件样式添加组件名前缀避免冲突

**代码检查**：
- 使用Stylelint检查LESS文件
- 运行命令：`yarn run lint:style`

## 6. 状态管理与DataSet

### 6.1 DataSet架构

DataSet是Choerodon UI特有的数据状态管理方案，类似于Redux但更轻量化和面向表单/表格场景。

**核心特性**：
- 内置数据校验（Validation）
- 支持CRUD操作的自动处理
- 内置分页、排序、筛选
- 支持主子表关联
- 支持查询数据集（QueryDataSet）

### 6.2 全局状态管理

项目中全局状态通过以下方式管理：

**1. 通过props传递**（推荐）：
```javascript
// 父组件
const ParentComponent = () => {
  const listDS = useRef(new DataSet(listConfig)).current;
  return <ChildComponent listDS={listDS} />;
};

// 子组件接收
const ChildComponent = ({ listDS }) => {
  // 使用listDS
};
```

**2. 通过HOC（高阶组件）**：
```javascript
import withProps from 'utils/withProps';

const EnhancedComponent = withProps((props) => {
  return <OriginalComponent {...props} />;
}, (props) => ({
  // 额外的props
}));
```

### 6.3 数据流规范

**单向数据流**：
1. 用户操作触发事件
2. 事件调用DataSet方法（如`query()`, `submit()`）
3. DataSet处理数据并更新状态
4. 组件重新渲染显示最新数据

**异步操作处理**：
```javascript
// 使用async/await处理异步操作
const handleSubmit = async () => {
  try {
    const result = await ds.submit();
    if (result) {
      notification.success({ message: '保存成功' });
    }
  } catch (error) {
    notification.error({ message: '保存失败' });
  }
};
```

```javascript
import dynamicWrapper from 'containers/dynamicWrapper';

{
  path: '/example',
  component: dynamicWrapper(() => import('./routes/ExamplePage')),
```

### 7.3 微前端路由配置

项目支持微前端架构，路由配置在 `.hzerorc.js` 中定义：

```javascript
hzeroMS: {
  exposes: {
    './lib/routers/RiskControlMonitorBusiness': './src/routes/RiskControlMonitorBusiness',
    './lib/routers/RiskDefiniton': './src/routes/RiskDefinition',
  },
}
```

### 7.4 路由守卫

通过 `src/config/router.js` 实现路由守卫逻辑，处理供应商和普通用户的权限隔离：

```javascript
function traversal(item, isSupplier = false) {
  const res = { ...item };
  if (isSupplier && item.FilterSupplier) return false;
  if (item.components !== undefined) {
    res.components = item.components.map((i) => traversal(i, isSupplier)).filter(Boolean);
  }
  return res;
}
```

## 10. 开发指南

```
└── stores/
    └── exampleDS.js  # DataSet配置
```

**步骤2：配置路由**

## 11. 常见问题与解决方案

### 11.1 构建相关问题

**问题1：内存溢出错误**
```
FATAL ERROR: CALL_AND_RETRY_LAST Allocation failed - JavaScript heap out of memory
```
**解决方案**：增加Node.js内存限制
```bash
NODE_OPTIONS=--max_old_space_size=8192 yarn run build
```

**问题2：模块解析失败**
**解决方案**：检查alias配置和路径别名是否正确

### 11.2 运行时报错

**问题1：DataSet未定义**
**解决方案**：确保在使用前正确初始化DataSet
```javascript
const listDS = useRef(new DataSet(config)).current;
```

**问题2：样式不生效**
**解决方案**：检查LESS文件是否正确导入，类名是否使用正确

### 11.3 调试技巧

**1. 使用React DevTools**：
安装Chrome扩展 "React Developer Tools" 进行组件树调试

**2. DataSet调试**：
```javascript
// 在控制台输出DataSet状态
console.log(listDS.current.data);
console.log(listDS.current.selected);
```

**3. API调试**：
浏览器Network面板查看API请求和响应

### 11.4 性能优化建议

1. **组件懒加载**：使用React.lazy进行路由级懒加载
2. **Memo化**：对复杂计算组件使用React.memo
3. **避免不必要的重渲染**：合理使用shouldComponentUpdate
4. **DataSet优化**：设置合适的pageSize，避免一次性加载过多数据
