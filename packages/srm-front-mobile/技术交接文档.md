# SRM Front Mobile 技术交接文档

## 一、项目概述

### 1.1 项目基本信息

| 属性 | 说明 |
|------|------|
| 项目名称 | srm-front-mobile |
| 项目描述 | 基于HZero平台的SRM供应商关系管理系统前端移动端 |
| 技术栈 | React + dva + webpack |
| 当前版本 | 1.67.0 |
| 仓库地址 | https://code.choerodon.com.cn/hzero-srm/srm-front-code.git |

### 1.2 项目定位

本项目是SRM（供应商关系管理）系统的前端模块，主要面向移动端应用场景，提供了采购助手、智能客服、寻商问品、消息管理、规则配置等核心功能。

## 四、路由架构

### 4.1 路由配置文件

路由配置主要在 `src/config/routers.js` 中定义，采用分层结构：

```javascript
// src/config/router.js
import oldRouters from './routers';

const getMsRouters = () => {
  const isSupplier = getUserOrganizationId() !== getCurrentOrganizationId();
  return oldRouters.map(route=>traversal(route, isSupplier)).filter(Boolean);
};
```

- `authorized: true` - 无需登录即可访问（公开路由）
- `FilterSupplier: true` - 租户层路由，过滤供应商用户
- `FilterSupplier: false` - 租户层路由，不过滤供应商用户

## 九、代码规范

### 9.1 ESLint 配置

继承 `react-app` 配置，关键规则：
- 禁用 `console.log`（除非配置 eslint-disable）
- React Hooks 规则检查
- JSX a11y 规则

### 9.2 Stylelint 配置

使用 Less 语法检查，配置在 `.stylelintrc`。

### 9.3 Git 提交规范

使用 Commitlint 校验提交信息，遵循 Conventional Commits 规范：

```
<type>(<scope>): <subject>

# 示例
feat(chat): add new AI chat component
fix(bug): resolve message sending issue
docs(readme): update project documentation
```

**允许的类型：**
- `feat`: 新功能
- `fix`: 修复bug
- `docs`: 文档变更
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建/工具变更

### 9.4 Prettier 配置

代码格式化工具，确保代码风格一致。

## 十三、升级指南

### 13.1 依赖升级注意事项

1. **React 版本**：项目已锁定 16.12.0，升级需全面测试
2. **choerodon-ui**：使用定制版本 `1.5.4-zhenyun.18`，需确认兼容性
3. **HZero 组件**：版本需与平台保持一致

### 13.2 代码迁移注意事项

1. **路径别名**：开发时使用 `@` 表示 `src/`
2. **组件引入**：优先使用 `_components` 和 `components` 别名
3. **工具函数**：优先使用 `_utils` 别名引用公共工具
